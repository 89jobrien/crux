# crux

Primary facade for the Crux agentic DSL. It gives Rust consumers one dependency for the runtime,
wire types, domain vocabulary, and attribute macros; implementation logic remains in the owning
crates.

## Architecture role

`crux` re-exports all of `crux-runtime` plus `crux-derive`'s `agent`, `harness`, and `evolve`
macros. With the `script` feature it also exposes `crux_script` as `crux::script`. Integration tests
and executable Rust examples live here so they exercise the public facade exactly as downstream
users do.

## Usage

```toml
[dependencies]
crux = "0.4.0"
```

```rust
use crux::prelude::*;

#[crux::agent]
async fn uppercase(input: String) -> Crux<String> {
    let value = x.step("uppercase", || async move { Ok(input.to_uppercase()) }).await?;
    Ok(value)
}
```

The macro-generated wrapper returns `Crux<String>`, whose result and recorded steps can be read with
`value()`, `causal_chain()`, `to_trace_json()`, or `to_mermaid()`.

## Key API

- `crux::prelude::*`: `CruxCtx`, `Agent`, `Crux<T>`, `CruxErr`, budgets, registry types, policies,
  and combinator support types.
- `#[crux::agent]`: generates a wrapper function and an `<Name>Agent` implementation.
- `#[crux::harness]`: generates harness configuration support for a named-field struct.
- `#[crux::evolve]`: generates an agent marked for harness evolution.

## Features

| Feature | Default | Effect |
| --- | --- | --- |
| `tokio-runtime` | yes | Enables the async runtime surface in `crux-runtime`. |
| `redb` | no | Enables the persistent redb registry adapter. |
| `tracing` | no | Enables runtime tracing instrumentation. |
| `script` | no | Re-exports `crux-script` as `crux::script`. |

## Implementation status

This crate is intentionally thin and owns no runtime behavior. Macro expansion is generated by
`crux-derive`; traces and combinators are implemented in `crux-runtime`; serializable records are in
`crux-types`. The examples cover manual agents, delegation, speculation, pipes, joins, and
confidence routing.

## Development and testing

```console
cargo nextest run -p crux
cargo clippy -p crux --all-targets -- -D warnings
cargo fmt --all -- --check
```

Use `cargo expand -p crux --test agent_macro` when inspecting generated macro code.
