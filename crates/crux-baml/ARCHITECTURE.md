# Architecture: crux-baml

Thin integration layer between BAML-generated client code and crux-script
handlers.

## Structure

```
crux-baml
 +-- baml_client/    (generated, gitignored)
 +-- extract.rs      — llm::extract handler
 +-- planner.rs      — llm::plan handler
```

## Code Generation

`baml_client/` is regenerated by `baml-cli generate`. The native lib
binary must match the platform. `just check-baml` validates version
alignment between `Cargo.toml` and `generators.baml`.
